# SUKOAA LearnMotion AI — Milestone 6: Camera and Fullscreen

Run `npm install` and `npm run dev`. Open http://localhost:3000/learn/solar-system and select 3D interactive.

- Full screen: top-right of 3D canvas. Press Esc or Exit full screen to return.
- Center / Reset view: returns the camera to a centered overview.
- Move scene: arrow buttons pan up/down/left/right. Drag the 3D canvas to rotate; right-drag to pan; scroll/pinch to zoom.
- Focus selected planet: moves the camera toward the selected planet.
- The scene now starts in an overview rather than automatically focusing Earth.

Other subjects remain planned: atomic structure, geometry, physics, chemistry and biology. This package improves the existing Solar System only; it does not claim those lessons are already implemented.

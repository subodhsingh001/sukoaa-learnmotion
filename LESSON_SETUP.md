# SUKOAA Lesson 1: Solar System

Install: `npm install` then `npm run dev`. Open `/explore/solar-system` and click **Start interactive lesson**, or visit `/learn/solar-system`.

Changes: added reusable `LessonPlayer`, `LessonQuiz`, `SolarSystemSimulation`, data in `data/solar-system.ts`, a lesson route and topic link, plus scoped CSS. No new dependencies.

The orbits are visual illustrations, not a scientifically scaled or gravitationally accurate simulation. Completion is saved to browser localStorage, not a user account.

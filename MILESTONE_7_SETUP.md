# Milestone 7: Multi-subject 3D lessons

New routes:
- /learn/atomic-structure (Hydrogen, Helium, Carbon, Oxygen; Bohr-style simplified model)
- /learn/geometry (cube, sphere, cylinder, cone; solid and wireframe)

Both use shared `Interactive3DStage` with fullscreen, orbit, zoom, pan, reset, and arrow movement. Existing Solar System, dashboard, Explore and quiz are preserved. Completion stored in browser localStorage.

Run `npm install` and `npm run dev`; test the two routes and `/learn/solar-system`.

This is a learning demonstration, not a physically exact atomic simulation.
